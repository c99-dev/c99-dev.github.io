# 최성호 웹 이력서

Python 백엔드 개발 경력과 개인·커뮤니티·교육 팀 프로젝트를 정리한 웹 이력서입니다.

- 웹 이력서: https://c99-dev.github.io/
- 칼바람 서비스 소스: https://github.com/c99-dev/aram-random-pick

## 구성

`index.html`에 경력과 프로젝트 본문이 있고, `resume-assets/`에 스타일·테마 및 인쇄 동작·프로필 사진이 있습니다. 프레임워크나 별도 빌드 없이 정적 파일을 게시합니다.

## 수정과 게시

`main` 브랜치의 루트를 GitHub Pages 게시 대상으로 사용합니다. 본문과 스타일을 수정한 뒤 push하면 게시됩니다. 사진·폰트·상대 경로, 모바일 화면, 테마 전환과 인쇄 레이아웃을 함께 확인합니다.

## 폰트

SUIT Variable의 공식 배포본을 사용합니다. 폰트의 저작권과 SIL Open Font License는 `resume-assets/fonts/LICENSE.txt`에 포함돼 있습니다.
